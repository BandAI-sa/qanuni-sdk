# مذكرة داخلية مختصرة عن معالجة البيانات

## طبيعة الخدمة

تقدم الشركة منصة اشتراكات رقمية وتطبيقًا للجوال يسمح للمستخدمين بإدارة الطلبات والاشتراكات والفواتير والإشعارات.

## أنواع البيانات

- بيانات تعريفية: الاسم، البريد الإلكتروني، رقم الجوال.
- بيانات تشغيلية: سجلات الدخول، عنوان IP، نشاط الاستخدام داخل المنصة.
- بيانات مالية جزئية: مرجع الدفع، حالة السداد، وسيلة الدفع.

## أغراض المعالجة

- إنشاء الحساب وتوثيقه.
- تشغيل الخدمة وتقديم الدعم.
- تحليل الاستخدام وتحسين الأداء.
- إرسال رسائل تشغيلية ورسائل تسويق للمستخدمين الموافقين.

## الأطراف الثالثة

تستخدم الشركة موفري استضافة وتحليلات ومراسلة وتذاكر دعم، وبعضهم يقدم الخدمة عبر بنية تحتية سحابية خارج المملكة.

## ملاحظات امتثال

لا توجد حاليًا سياسة تفصيلية منشورة تعالج حقوق أصحاب البيانات أو مدد الاحتفاظ أو النقل الدولي بصورة كافية.
